# Interview

Skill de simulation d'entretien d'embauche réaliste : un agent joue le recruteur et le coach.

## Contenu

- `SKILL.md` : instructions pour l'agent IA (cadrage, déroulé en 4 phases, grille d'évaluation, bilan final).

## Fonctionnement

- Demande d'abord le poste visé, le niveau, la fiche de poste et le mode (bienveillant, exigeant ou pression).
- Déroule l'entretien en 4 phases : présentation, compétences, mises en situation (méthode STAR), questions du candidat.
- Après chaque réponse : un retour critique bref, puis la question suivante. Une seule relance de précision si la réponse est creuse.
- Termine par un bilan noté selon une grille d'évaluation.

## Utilisation

Charge le skill dans ton agent, puis demande une simulation d'entretien en donnant la fiche de poste.
