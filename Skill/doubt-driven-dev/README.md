# doubt-driven-dev

Skill qui impose un doute méthodique et vérifiable aux réponses non triviales.

## Contenu

- `SKILL.md` : instructions pour l'agent IA (déclencheurs, boucle en cinq étapes, épreuves de réfutation, contrat de sortie).

## Fonctionnement

- Une réponse confiante n'est pas forcément correcte : le skill transforme le doute en procédure.
- Il s'applique aux livrables non triviaux : code, analyses, chiffres, plans, affirmations factuelles.
- La boucle : formuler les hypothèses, les isoler, les mettre à l'épreuve, réconcilier, puis s'arrêter.
- Tout doute doit déboucher sur un test, une décision ou une question fermée. Un doute sans suite est du bruit.

## Utilisation

Charge le skill dans ton agent pour les tâches où une erreur coûterait cher. Le mode standard+ est le mode par défaut : rigoureux mais économe.
